
 💼  **Developer Portfolio**

Welcome to my personal developer portfolio website. This site showcases my projects, skills, and a little about me. It is built with HTML, CSS, and JavaScript and includes interactive animations powered by AOS (Animate On Scroll).

## 📌 Features

- 🖥️ Clean and responsive design
- 📂 Project showcase section with localStorage support
- ✨ Smooth scroll animations with AOS
- 📞 Contact form (UI only)
- 💬 "Get in Touch" section for user inquiries
- 🔗 Footer with clickable social media icons (GitHub, LinkedIn, Email)

## 📁 Project Structure

📂 portfolio/
├── index.html          # Homepage
├── projects.html       # Projects listing page (dynamic)
├── contact.html        # Contact form
├── style.css           # Stylesheet
├── script.js           # JavaScript logic for project handling
└── assets/             # Logos, icons, and images

## 🚀 How to Run

Just clone the repo and open `index.html` in your browser.

git clone https://github.com/harshithabhat04/portfolio.git
cd portfolio
start index.html

> No additional dependencies needed — it's all front-end!
